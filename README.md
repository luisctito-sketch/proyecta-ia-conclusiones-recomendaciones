URL esperada al activar GitHub Pages:

`https://luisctito-sketch.github.io/proyecta-ia-conclusiones-recomendaciones/`

## Objetivo del módulo

Revisar si el Capítulo VI cierra correctamente el Proyecto de Grado mediante:

- relación problema ↔ Objetivo General ↔ Objetivos Específicos ↔ resultados;
- conclusiones sustentadas en evidencia;
- reconocimiento del grado de cumplimiento y de dificultades reales;
- recomendaciones vinculadas a limitaciones y continuidad tecnológica;
- transición de prototipo o sistema experimental hacia una solución final;
- redacción científica, impersonal y coherente.

## Regla pedagógica

El módulo NO redacta el capítulo por el estudiante. Diagnostica qué está bien, qué falta y cómo corregirlo.

## Carga de documentos

Se admiten archivos:

- `.docx`
- `.pdf`
- `.txt`

La extracción se realiza en el navegador mediante Mammoth.js y PDF.js. También se puede pegar directamente el texto.
